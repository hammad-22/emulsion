# MOV-82 proof: display-referred photos

Renders and numbers from the opt-in probe `DisplayReferredProof` (`EMULSION_PROOF=<dir> swift test --filter DisplayReferredProof`), run on a synthetic Display P3 chart: a 256-step gray ramp, a near-white sky gradient, and saturated patches. `before/` is the code before MOV-82; `after/` is this change. Each folder holds the source chart, the render at zero edits, at −3 EV and at +2 EV, and `numbers.txt`.
