# MOV-121 proof: shoot with a recipe

iOS Simulator captures from the top of the MOV-121 branch. The Simulator has no camera: the viewfinder shows the stand-in camera (bundled synthetic sample photos) rendered through the live film look. iPhone 17 Pro shots come from the UI walkthrough. iPhone Duo poses were set on a spare simulator with agent-device 0.21.31 `fold closed` / `fold open`; the tool could not read the hinge angle back, so each pose was confirmed by which panel was lit (outer 466x678 pt, inner 951x669 pt). Timing overlays are Simulator numbers, not device numbers. No device captures yet.
