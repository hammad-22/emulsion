# Metal / Core Image kernels

- Two sources of Core Image color kernels (`extern "C"`, `coreimage::sample_t`), linked into one metallib per platform by `Tools/build-kernels.sh` (`metal-link`, since `metallib -cikernel` takes one input):
  - `Emulsion.ci.metal`, the film process. Swift mirrors: `FilmModel.swift`, `FilmModel+Display.swift`, `ColorSpaces.swift`, `Halation.swift` and `Grain.swift`; loaded by `Kernels`.
  - `Digicam.ci.metal`, the digicam process. Swift mirror: `DigicamModel.swift`; constants arrive as arguments from `DigicamLook`; loaded by `DigicamKernels`. Its `digicamLuma709`, `digicamHash` and value-noise lattice copy `lumaSRGB` and the film file's former value-noise grain (`hash`, `valueNoise`, replaced there by `pcg4d` in grain v2, MOV-30); share a header later.
  - Function names are global across both files: prefix digicam ones with `digicam`. Change a kernel and its mirror together, using the same names for constants.
- Rebuild with `sh Tools/build-kernels.sh` and commit all three metallibs (macOS, iOS, simulator) together with the source. The deployment target in the script must match `Package.swift`.
- Each kernel gets a comment stating its input and output: scene or display light, working or P3 primaries, premultiplied or not.
- The kernel-argument layout (`kernelArguments`, `misc`/`neg` vectors) is an ABI: when it changes, update the comment block above `filmRender` and the Swift packing together.
- `mirroredEdges` is a warp kernel (edge reflection for halation's blurs) and `gaussianPass` a sampler kernel (exact Gaussian taps for halation's narrow blurs and grain clumps); everything else is a color kernel. `grainNoise` is a generator (no input image, integer pixel coordinates, integer hash: keep it integer-exact so every device draws the same grain, `GrainTests.noiseIsTheSameOnEveryDevice`). Halation's glow (`halationMix`) and the grain noise enter the film kernels as samplers and act on layer exposure and negative density there; a missing one gets a black sampler and k = 0 (or σ·0), which must leave the render unchanged. With both off the renderer runs `filmSystemPlain` / `filmSystemRelativePlain`, which must match the full kernels at k = 0 and zero noise up to float rounding (< 1e-3 codes; the compiler schedules the full kernel differently, `HalationTests.halationZeroIsTheCleanRender`).
- Pointwise math belongs in color kernels. Spatial work (blurs, local tone) uses Core Image filters at reduced resolution where it's invisible.
- Watch the per-pixel cost: no new loops or bisection in the live path without measuring.
- Hashes and noise must stay deterministic for a seed and decorrelated across seeds (see the grain tests).
