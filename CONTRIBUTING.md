# Contributing

Thanks for helping. A few rules keep the engine trustworthy:

- Follow [AGENTS.md](AGENTS.md): branch per topic, tests first for bugs, `swift test` and `swift format lint` must pass, and every PR has a **Proof** section (before/after renders or screenshots).
- **No third-party copyleft code or data** (GPL, AGPL, LGPL, CC BY-SA). The project is AGPL-3.0-only and the copyright holder must own every line, so the app can ship on the App Store. Cite papers and sources; don't copy code.
- Don't claim something matches a real film stock without a measurement or a primary source.
- Outside contributions need a signed contributor licence agreement before they can be merged. One isn't set up yet (MOV-94), so please open an issue to discuss a change before sending a pull request.
