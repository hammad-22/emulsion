# Contributing

Thanks for helping. A few rules keep the engine trustworthy:

- Follow [AGENTS.md](AGENTS.md): branch per topic, tests first for bugs, `swift test` and `swift format lint` must pass, and every PR has a **Proof** section (before/after renders or screenshots).
- **No GPL-licensed code or data.** The project is Apache-2.0. Cite papers and sources; don't copy code from incompatible licenses.
- Don't claim something matches a real film stock without a measurement or a primary source.
- By contributing, you agree your contributions are licensed under Apache-2.0.
